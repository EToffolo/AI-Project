# AI-Project

Repositório para desenvolvimento do projeto de MM845.

## Tema do projeto

Aplicar IA na pesquisa matemática para predizer a métrica induzida por uma estrutura G2.

## Stack planejada

- Visual Studio Code
- Python
- PyTorch
- Jupyter Notebook

## Setup rápido

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
